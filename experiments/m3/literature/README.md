# M3 literature alphabets (Henn-style examples)

These are minimal, rational alphabets inspired by canonical differential
equation examples in:

- J. M. Henn, "Lectures on differential equations for Feynman integrals,"
  J. Phys. A 48 (2015) 153001.

The letter sets here are simplified toy alphabets intended for deterministic
experiment runs and regression checks, not full physics model coverage.
